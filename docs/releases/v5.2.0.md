# GaiaGIS v5.2.0 — Multilingual Source GIS

## What's New

- Select EN, FR, DE or ES game data independently of the GaiaGIS interface language. The selected archive pair is used consistently by source builders.
- Build the complete 20-asset Workspace for the chosen sources. Cache reuse is isolated by source role and content fingerprint; only geometry with identical MAP hashes is shared.
- Preserve each language's own archive keys, fingerprints, EV offsets and Field evidence. Foreign-source records are not assigned to English source identities.

## Compatibility

- Existing English Workspaces remain supported. Switching source language does not require rebuilding GIS products, and the existing WM0, Native, Explorer and Field interfaces remain available.
- Source imports remain local. GaiaGIS does not rename or modify original game files.

## Known Limitations

- The strict Field reader currently rejects five FR scenes (`losin3`, `trnad_2`, `itown_w`, `itown_i`, `itown_m`) and one DE scene (`cosmin7`); these remain unavailable or Unknown rather than being repaired.
- Complete L3 evidence and original-game runtime behavior have not been verified for all four languages.
- Static WM0 world-state prediction remains Unknown for FR, DE and ES; only the fingerprint-validated English script is used for prediction.
- Game data language and GaiaGIS UI language are independent. Support for these four data sets does not establish compatibility with every game edition or language.

Users must provide data from a legally owned Final Fantasy VII installation. GaiaGIS does not distribute original game files or private Workspace data.
