# GaiaGIS v5.4.0 — WM0 Topology Evidence Explorer

## What's New

- Analyze topology evidence across all 142,586 original WM0 BASE triangles using exact 3D positions and raw edge occurrences. Inspect boundary, non-manifold candidate, collapsed/repeated edge and duplicate-face evidence.
- Browse seven paged filters with source-face location/highlight. The existing Source Inspector now shows all three edge slots, source references and topology diagnostics.
- Separate raw edge incidence, exact X-periodic seam evidence and actual source-matched Routing CSR adjacency. The current source reports 214,270 raw edge keys, 1,030 boundary keys, 124 non-manifold candidate keys, 84 duplicate-face excess records and 224 confirmed X seam pairs.

## Compatibility

- Reuses the existing V1 Workspace and WM0 Source GIS; no data regeneration or format migration is required.
- Original geometry, Workspace Manifest, Routing CSR, GeoPackage, Native, Field, Save, World Variants and 13 projections remain unchanged.

## Known Limitations

- These are static source-geometry and topology diagnostics. They do not establish game collision, traversability, story access or original runtime behavior.
- X seam pairs are confirmed only by exact unique source matching. Raw edge counts are preserved; Z is not periodic.
- Ambiguous or unavailable Routing CSR relationships remain explicit and are not guessed. No path-planning, Dijkstra, transport-mode or terrain-eligibility rules are changed.
- These source mesh diagnostics do not establish physical or planetary geographic topology.

Users must provide data from a legally owned Final Fantasy VII installation. GaiaGIS does not distribute original game files or private Workspace data.
