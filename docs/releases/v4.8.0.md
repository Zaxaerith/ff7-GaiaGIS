# GaiaGIS v4.8.0 — Native Multi-Surface Query & Transect Analysis

## What's New

- Query all WM2/WM3 source faces at an entered X/Z position or by explicit top-down picking. Fractional inputs, shared edges, duplicate sources, separate heights, vertical intervals and degenerate faces retain their source identities.
- Create source-linked SVG transects that distinguish ordinary height segments, point contacts, gaps, vertical crossings and collinear height bands. Select a segment or source record to inspect its Native face.

## Compatibility

- Uses existing Native v1 data and the shared Inspector. No new Workspace resource or GIS export format is required; existing WM0 reconstruction and Native v1 source records remain unchanged.
- Controls are available in all five supported languages. Existing map, Field and Workspace switching releases query and pick state.
- GDAL and QGIS remain optional local tools. The portable Viewer does not bundle them.

## Known Limitations

- WM2 and WM3 use independent raw Cartesian source coordinates. Values are not verified metres, altitude or globally registered positions.
- Area totals are source-triangle contribution sums, not unioned terrain area. Queries do not infer a preferred ground surface, collision, walkability, navigation or gameplay behavior.
- Transects report source geometry evidence; they do not fit a continuous ground curve across source faces.

Users must provide data from a legally owned Final Fantasy VII installation. GaiaGIS does not distribute original game files or private Workspace and research data.
