# GaiaGIS v4.5.0 — Field Script Evidence & Spatial Registration Lab

## What's New

- Index static background and Palette script evidence across all 702 Fields, including verified opcode spans, entry ownership, bounded control-flow context, Group/Layer associations and preserved unknown stops. Static reachability is not proof that the original game executed an instruction; evidence selection never changes the background, and preview requires an explicit research action.
- Inspect source Camera projection inputs and outputs, candidate FieldLocal points, clipping and ambiguity without treating a screen position as a unique world location or visibility proof.
- Use the Spatial Registration Lab to load a user-selected private PNG, record explicit image-to-Camera mappings and manual control points, and inspect residuals with exclusion reasons.

## Improvements

- Field script evidence is a separate optional Workspace resource with source binding, per-scene integrity checks, bounded decompression, and incremental update/recovery support. Older Workspaces without it continue to use their existing Field, Camera, Background, Interaction and GIS capabilities.
- PNG structure, dimensions, pixels and metadata are checked against explicit size limits. Reference images stay in the browser session; research export contains source and measurement metadata but not the image or its filename.
- Workspace replacement, Field/Camera changes, repeated imports and return to World release stale image, Canvas and asynchronous resources.

## Compatibility

- Existing Visual Pack v1/v2 and generator-3/generator-4 readers, Context 3, Interaction v1, Walkmesh v1, GIS products and GeoPackage v1/v2 remain supported.
- The new `gaia-field-script-evidence.bin` resource is generated and used locally. It is not included in this release. Users must provide data from a legally owned Final Fantasy VII installation; this project does not distribute original game files, private Workspaces, reference frames or a complete derived dataset.

## Known Limitations

- Static script indexing does not prove that an instruction was executed by the original game. It does not evaluate runtime variables, story state, initialization or a complete script VM.
- **Original runtime registration = NOT VERIFIED.** No original-runtime reference frame was available to validate game-level Camera/Walkmesh alignment or image-registration accuracy. Exact mathematical agreement with the projection formula is not pixel-registration evidence.
- Indexed blend Type 0/3 and PC16 blending remain unsupported. Layer 2/3 runtime scrolling, Palette animation, wrapping and dynamic depth are not implemented.
- PNG import accepts bounded non-interlaced 8-bit RGB/RGBA images only, up to 8 MB, 4 million pixels and 4096 pixels per side. Mapping and control points must be entered by the user; the tool does not automatically calibrate a Camera.
