# GaiaGIS v1.0.0

## Highlights

- Mathematical reconstruction of FF7's polygonal world map: periodic topology analysis and inverse-Mercator parameterization.
- Earth-sized reference Gaia sphere, with explicitly assumed scale and synthetic polar ocean caps.
- Local GIS products, custom Gaia CRS and standard projected views.
- Interactive Three.js Web viewer: Globe, Equirectangular, Mercator, Mollweide and Orthographic, with smooth projection morphing.
- Gameplay terrain and region visualization/navigation, triangle grid and labeled graticule.
- Triangle provenance inspection, preserving source map/section/mesh/triangle identity.
- Desktop/mobile interaction, keyboard navigation, reduced-motion support and browser-local data loading.

## Research note

V1 Geometric Gaia is the canonical GaiaGIS reconstruction, not official/canonical Final Fantasy VII geography. Climate V2/V2.1/V2.2 research concluded **Experimental / Inconclusive**. No climate latitude warp was adopted.

## Data policy

This is a **code-only public release**. No proprietary FF7 files or complete derived Gaia geometry are distributed. Users use their own FF7 installation to generate the default V1 dataset locally, then load gaia-meta.json and gaia-mesh.bin together through the Viewer. Files stay in the browser and are not uploaded.

GitHub's automatic source ZIP/TAR archives are the release downloads. No private datasets, generated output, geometry or screenshots are attached. The manual Pages workflow builds the same code-only Viewer. Game-derived geometry distribution remains a separate, unresolved matter.
