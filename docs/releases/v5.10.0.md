# GaiaGIS v5.10.0 — Gameplay Event Geography & Script Provenance

## What's New

- Add Field Gameplay Event evidence lookup with filters for Field, Actor, Slot, Entry, offset, record type and geometry status. Read-only links connect Interaction, Script Evidence and Gameplay sources.
- Trace interactions and Walkmesh triangles in both directions while preserving every exact 3D contact candidate. Query directed static reachability from a verified Entrance or Gateway Arrival, with source Triangle, Access slot, offset and record evidence.
- Add WM0 World Event Geography analysis with original Region/Terrain trigger-face counts and raw horizontal-projection area contributions. Separate events with trigger-face evidence, model-placement anchors and unresolved script observations; reuse the WM0 Source Inspector.
- Connect event, Gameplay and Formation evidence to existing guides. Reuse the Field Canvas, Inspector and five-domain navigation.

## Compatibility

- Preserve original record identities and spatial precision. No private Workspace, game data or save files are included in the public release.

## Known Limitations

- Matching Actor/Entry identities, geometric contact and static reachability do not prove that an event executes.
- The analysis does not create inferred reward coordinates, chest locations, collection flags or story state.
- World Battles without a spatial anchor are not automatically located. The Viewer does not simulate original runtime event triggers or story conditions.
- Raw area values describe source geometry in raw coordinate units; they are not km² or physical measurements.
