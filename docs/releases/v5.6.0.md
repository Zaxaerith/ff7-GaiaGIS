# GaiaGIS v5.6.0 — Regional Connectivity & Explorer UX

## What's New

- Add WM0 Regional Connectivity & Boundary Explorer for the 142,586 source BASE triangles. Strict Raw (A) reports 210 connected components; Strict + Confirmed X Periodicity (B) also reports 210. The source has 3,198 confirmed cross-Region edges, 40 Region-adjacency pairs and 224 confirmed X-periodic seam pairs.
- Highlight source components, display selected boundaries and inspect face/edge provenance alongside existing POI and Atlas source associations.
- Keep geometric topology distinct from game transportation and routing. Duplicate faces remain separate source nodes, and ambiguous contacts do not create connections.
- Organize the Viewer into five task areas: World, Character Explorer, Game Guide, GIS Analysis, and Data & Settings. The GIS directory exposes 19 directly searchable tools, with a separate operation area and shared Inspector. Desktop uses a navigation rail; mobile uses bottom navigation.

## Explorer UX and Character Rendering

- Restore Repeat sampling for integer-tile UVs in original FF7 character models, fixing missing eye and mouth textures on affected characters.
- Resolve roaming direction-key placement, duplicate prompts, and conflicts between the Explorer HUD and Inspector.
- Retain the classic deep-blue gradient and 3px silver-white window borders. Navigation changes preserve valid Workspace, Viewer and analysis state.
- Character fixes use existing model data, skeletons, animation and textures. No original game files were modified and no Explorer resource set was regenerated for this release.

## Compatibility

- Preserve WM0/WM2/WM3, Field, all 13 projections, Routing, Atlas, Gameplay, Save and the existing two-stage Windows launch flow.
- Regional analysis reuses the existing WM0 topology and source identities. It does not change game data formats, GIS mathematics or Workspace assets.

## Known Limitations

- Regional connectivity is geometric evidence, not proof of character traversability or gameplay reachability. Duplicate faces can remain isolated nodes.
- Raw source area and boundary length are not calibrated physical geographic measurements.
- Character roaming is a static GIS preview and does not simulate the full Final Fantasy VII runtime.
- Initial analysis performance varies by device. The updated Windows Tk appearance and physical mobile touch interaction have not had comprehensive real-device coverage for this release.

GaiaGIS does not distribute copyrighted Final Fantasy VII assets. Users must provide data from a legally owned, supported game installation.
