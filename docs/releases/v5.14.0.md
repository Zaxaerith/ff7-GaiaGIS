# GaiaGIS v5.14.0 — World–Field Integrated Exploration & Spatial Continuity

## What's New

- Connect existing WM0 Routing and Journey results to verified Field Entrance records and directed Walkmesh networks. Select and lock an Entrance together with its explicit Default or Alternative scenario before world-route eligibility checks and path solving.
- Preserve the WM0 arrival Source Node, ENTER_FIELD provenance, FIELD.TBL record, and FieldLocal arrival Triangle. Explore zero to three Gateway transfers, optionally continuing to a final Triangle or original Interaction LINE target.
- Continue searching valid Arrival states when an initial arrival cannot reach the selected local target. Distinguish Triangle states within the same Field and retain original Gateway records, directed Access paths, contact candidates, and arrival identities.
- Report completed static chains, bounded searches, unavailable evidence, and verified static disconnection as distinct outcomes.

## Verified Source Coverage

- A feasibility census validated all 43 existing WM0 POI Entrances for structural World-to-Field handoff, covering 34 locations, 40 distinct Fields, and 1,064 distinct CSR Source Nodes. This describes the existing POI subset, not every original-game Entrance.
- Kalm demonstrates a verified world-route endpoint followed by local LINE reachability. Midgar demonstrates a continuous three-Gateway static exploration chain. Mythril Mine demonstrates different reachability outcomes from distinct actual Arrival Triangles.
- Shared world trigger nodes can lead to different explicitly selected Entrance scenarios. These are source-validated static relationships, not guarantees of original-game runtime accessibility.

## UI and Compatibility

- Integrate segmented exploration with the existing Journey interface, World Viewer, Field Canvas, Graph, and shared Inspector. Inspect route segments and restore the existing world route without unnecessary recomputation.
- Preserve Gameplay, Dialogue, Conditional Evidence, Atlas browsing, and all five UI languages.
- Reuse existing Workspace assets without private file generation or Manifest migration. Preserve ordinary Journey and Field Gateway query behavior.

## Known Limitations

- This release supports World-to-Field handoff; it does not introduce verified reverse Field-to-WM0 routing.
- FieldLocal and WM0 remain independent coordinate spaces. World reference-sphere distances and local Access hops are reported separately; no combined physical distance or gameplay travel-time estimate is provided.
- The Viewer does not evaluate runtime story conditions, switch vehicles, or simulate collision. MAPJUMP and REQ references do not become spatial routing edges.
- LINE geometry does not establish event, NPC, or reward coordinates. Returning to the World Viewer is a view operation, not a verified in-game exit.
