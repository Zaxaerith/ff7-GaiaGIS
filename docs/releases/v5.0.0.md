# GaiaGIS v5.0.0 — Global Source GIS & Integrated Spatial Analysis

## What's New

- Query all 142,586 original WM0 base source faces at a raw X/Z point or along a straight transect, preserving source identities, exact height evidence, shared edges, duplicates and vertical intervals.
- Inspect global multi-surface profiles with explicit horizontal periodic-boundary handling. Entered unwrapped X coordinates determine seam direction; no shortest-path rewrite is applied.
- Link source faces and profile branches to existing Terrain, Encounter, Event, Entrance, Atlas and Field context evidence in the shared Inspector.

## Compatibility

- Uses the existing private V1 Workspace and source data. No Workspace or GIS rebuild is required; existing WM0, Native, Field, Explorer and Variant research formats remain compatible.
- Global source queries use the original base surface and remain separate from synthetic polar reconstruction and display projections.

## Known Limitations

- Coordinates and heights are raw source units, not verified metres or globally registered positions. Horizontal X wraps explicitly; Z does not wrap.
- Encounter, Event, Entrance and Field links are static source evidence. They do not establish runtime availability, executed game logic, player landing or gameplay behavior.
- Queries do not infer a unique ground surface, collision or navigation. The 9,792 synthetic polar faces are outside original-source queries.

Users must provide data from a legally owned Final Fantasy VII installation. GaiaGIS does not distribute original game files, complete derived datasets or private Workspace data.
