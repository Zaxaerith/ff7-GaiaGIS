# GaiaGIS v5.8.0 — Encounter Geography & Formation Evidence

## What's New

- Add a WM0 Encounter Geography GIS analysis for Encounter Sets, Formations and composite Scene/Enemy identities. Inspect all table references or bounded candidates derived from historical static rules.
- Review Region, Terrain and Set counts, raw² source-area contribution and original record evidence. Navigate between source faces, records and the shared Inspector.
- Use an independent thematic map mask without changing existing layers or analysis state. Available in all five UI languages and existing projections.
- Validate 252 positive-weight relationships, static candidate coverage for 192 Formations and 21,942 ordinary static candidate source faces.

## Compatibility

- Preserve existing Workspace, WM0 GIS, Routing and map-layer behavior. Journey planning remains unchanged; along-route encounter summaries are not part of this release.
- No private game-derived data is bundled. Features that require a Workspace use data generated from original game files the user legally provides.

## Known Limitations

- Static candidate coverage is evidence from source records, not an actual encounter probability or a guaranteed spawn location.
- This release does not add automatic encounter routing, probability simulation, or Field, WM2 or WM3 encounter analysis.
- Counts and raw² values describe source records and source geometry; they do not establish runtime behavior or physical geographic measurements.
