# GaiaGIS v5.15.0 — Encounter-aware Journey Analysis

## What's New

- Analyze encounter evidence along verified WM0 routes from ordinary Routing, ordered multi-stop Journeys, and World–Field Exploration. Reuse the Route Profile's verified face-interior corridor segments with source-face identity and traversal order intact.
- Inspect Encounter Set intervals, positive-weight Formation references, and validated composite Scene/Enemy identities. Analyze a whole journey or individual legs without changing the routing solver or CSR weights.
- Distinguish graph cost, sampled corridor length, traversed pieces, and unique source faces. Repeated traversal contributes to distance while original source-face identities are deduplicated; repeated Formation and composite Enemy associations are deduplicated within each traversed piece.
- Report ordinary and Chocobo static candidate coverage separately, including intersection and union. Preserve all-table-reference and historical-rule candidate scopes, including inactive sets, script gates, and zero-weight source records.

Candidate distances may overlap. Coverage percentages are not normalized encounter probabilities.

## Verified Examples

- The Midgar → Kalm → Midgar reference journey contains 116 traversed corridor pieces, 30 unique original source faces, and seven encounter evidence intervals, over approximately 5,286.896 reference-sphere kilometres.
- The Chocobo Farm reference route demonstrates overlapping ordinary and Chocobo candidate coverage without double-counting their union.

These measurements describe the current source-derived route model, not canonical Final Fantasy VII distances or runtime encounter frequencies.

## Visualization and Integration

- Add a shared Encounter Analysis panel to ordinary Routing, ordered Journeys, and World–Field Exploration. Explore distance-based Encounter Set strips, Formation/Enemy filtering, pagination, and per-leg results.
- Highlight selected verified face-interior route segments with the existing projection system and antimeridian handling. Route, encounter geography mask, and other thematic layer states remain independent.
- Reuse the Source Inspector, Formation/Enemy guides, and Encounter Geography tools. Preserve the existing five UI languages and responsive layouts.

## Compatibility

- Reuse existing Workspace assets without private file generation or Manifest migration.
- Preserve Route Profile when Encounter data is unavailable. Retain direct Encounter Set and raw positive-weight Battle ID evidence when Gameplay associations are unavailable or rejected.
- Distinguish unavailable Enemy evidence from verified zero-candidate coverage. Completed per-leg analysis remains available when a full journey exceeds the analysis budget.
- Invalidate obsolete route evidence when its source or Workspace changes.

## Known Limitations

- Static candidate coverage does not establish actual random encounter probability, danger, expected battle count, or runtime encounter eligibility.
- GaiaGIS does not simulate RNG, step counters, Chocobo Lure, story state, or runtime vehicles. It does not calculate encounter-avoidance routes or change Dijkstra weights.
- Analysis is limited to verified WM0 world-route segments. Field, WM2, and WM3 encounter analysis is not introduced; Field Access hops and Gateway transfers do not contribute to world-route encounter distances.
- Reference-sphere distances are not official game-world measurements.
