# GaiaGIS v5.13.0 — Field Conditional Event Geography & Control-Flow Evidence

## What's New

- Analyze bounded static control dependencies in verified Field control-flow graphs. Dominator and post-dominator evidence distinguishes standard, strong, and all-owning-roots core relationships while retaining Actor, raw Slot, Entry, instruction offsets, and source identities.
- Across 702 available English Field scenes, accept 54,545 acyclic raw Entry roots and identify 11,621 core-controlled existing events across 532 Fields. Existing MESSAGE, ASK, STITM, SMTRA, BATTLE, and REQ-family references remain unchanged.
- Show bounded local raw-address associations for ASK/IF, including uncertain writes, aliases, and unknown side effects. Expose explicit one-hop REQ/REQSW/REQEW target evidence without propagating request-source conditions into target events.
- Integrate Conditional Evidence with the Field UI and shared Inspector, including filtering, source inspection, bounded pagination, links to available Interaction LINE evidence, and all original surface-contact Triangle candidates.

These are static control relations for existing records, not newly discovered events or verified runtime occurrences. The 771 ASK/IF associations do not establish actual player-answer provenance; 23,970 REQ one-hop candidates are not verified scheduling outcomes.

## Compatibility and Performance

- Reuse the v5.12 Workspace and CFG resources. No new private binary asset or Manifest/Workspace migration is required.
- Analyze only the current Field on demand, with Worker cancellation and bounded budgets. Legacy and incomplete source groups report their limitations explicitly.
- Preserve WM0, WM2, WM3, Walkmesh, Visual, Gateway, Atlas, and other GIS capabilities. Original Actor, raw Slot, Entry, offsets, and source identities remain available for inspection.

## Known Limitations

- Static CFG dependencies do not verify original game runtime execution. GaiaGIS does not evaluate story conditions, run the original VM, simulate save states, or predict player choices.
- No NPC, battle, dialogue, or reward coordinates are inferred. Same-Actor LINE associations do not establish event locations, runtime triggers, or causal execution.
- Request targets are static candidates. Cyclic, incomplete, ambiguous, or over-budget CFG proofs remain Unknown rather than being inferred.
