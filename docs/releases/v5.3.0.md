# GaiaGIS v5.3.0 — Verified Script Evidence & Field Recovery

## What's New

- Provide WM0 initialization predictions for EN, FR, DE and ES using four reviewed complete `wm0.ev` SHA-256 identities. Preserve signed progress and original condition-bit semantics. Missing, modified or conflicting sources remain **Unknown**; predictions never change visible terrain, BASE routing or manual World Variant selection.
- Recover bounded Script, Walkmesh, Interaction and related Field evidence for six exact source members: FR `losin3`, `trnad_2`, `itown_w`, `itown_i`, `itown_m`, and DE `cosmin7`. Recovery is limited to reviewed archive/member hashes and retains source boundaries and rejection reasons.
- Strict Visual is available for FR `losin3` and DE `cosmin7` as `static_complete`, and FR `trnad_2` as `static_partial`. Visual remains unavailable for the three FR `itown` scenes because their 16-byte trailing data is not an accepted footer; that data remains strictly rejected.

## Compatibility

- Read existing Field Context v1–v4. Context v5 adds declared length, used Section-1 span and original member SHA-256 evidence.
- Existing English Workspaces remain readable. World/V1/Native geometry is unchanged; dependent Field products can be refreshed without rebuilding unchanged world geometry.

## Known Limitations

- These are static script and source-data findings, not verification of original-game runtime state or behavior. The recovered Field scenes have not been validated in the original game.
- Complete four-language game-logic equivalence has not been established. Foreign WM2 scripts retain variable-address-space differences as research evidence.
- The three FR `itown` Visual resources remain unavailable until their trailing-byte format is verified. No source bytes, script offsets or Triangle IDs are repaired.
- No save write-back or automatic story-state synchronization is provided.

Users must provide data from a legally owned Final Fantasy VII installation. GaiaGIS does not distribute original game files or private Workspace data.
