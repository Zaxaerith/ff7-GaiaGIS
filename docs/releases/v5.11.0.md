# GaiaGIS v5.11.0 — Field Dialogue Geography & Conditional Evidence

## What's New

- Query `MESSAGE`/`ASK` references by Text ID and find source references from a message. Preserve Actor, Script Slot, Entry, offset and source identity, including multiple references and script aliases. The validated English source contains 14,000 reachable dialogue references.
- Optionally preview 12,413 referenced, validated entries from the private local `gaia-field-dialogue.bin` asset. Names, control codes, buttons, waits and dynamic content are shown with explicit markers. Dialogue text language is independent of the five UI languages.
- Inspect explicit Actor/Entry request relations for `REQ`, `REQSW` and `REQEW`, along with bounded `ASK`/`IF` parameters, answer write targets and static branch evidence.
- Follow evidence across Field Interaction, Gameplay, Walkmesh, Gateway and the shared Inspector.

## Compatibility

- Existing Workspaces remain usable with the current Viewer. Older Viewers are not guaranteed to accept a Manifest containing the new asset.
- The private dialogue asset is generated and loaded locally; no original dialogue text or private data is included in this Release or Pages.

## Known Limitations

- Dialogue references, requests, Actor identity and static reachability do not prove runtime execution. The Viewer does not infer story conditions, actual choices or Save state, and creates no NPC coordinates or spatial markers.
- World Battles without a spatial anchor are not automatically located.
- CMUSC retains its existing parsing coverage; 24 partial scenes are not upgraded to complete.
