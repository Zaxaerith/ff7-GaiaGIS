# GaiaGIS v4.4.0 — Field Background Compositing & Layer Research

## What's New

- Compose supported indexed Layer 1 Type 1 saturated-add and Type 2 clamped-subtract tiles in the retained Z/Sub order.
- Control Layers 0–3 independently, inspect per-layer support and omission counts, view opaque tiles only, and outline supported blend tiles.
- Optionally preview Layer 2/3 at their original 32×32 raw positions. This research view is labelled Experimental and is disabled by default.
- Continue to inspect explicit Group/State and Trigger associations in the Background State Explorer. A Trigger selection alone does not apply a state.

## Improvements

- Across 702 Fields, the static base profile reports 695 drawable backgrounds: 617 complete and 78 partial; seven malformed or unsupported source scenes remain rejected. Static completeness does not mean the original game-runtime image has been restored.
- Visual transport v2 preserves old Visual Pack v1 and generator-3 reader semantics. Workspace updates retain unrelated GIS products and existing recovery pairs.
- Development tooling includes read-only workspace auditing, documented retention rules, and non-destructive QA failure evidence handling.

## Compatibility

- Existing Workspaces, Visual Pack v1 and generator-3 resources, Field/GIS data contracts, and GeoPackage v1/v2 remain supported.
- GaiaGIS is a reader and research viewer. Users must provide data from a legally owned Final Fantasy VII installation. Original game files, private Workspaces, complete derived datasets, and QA evidence are not included in this release.

## Known Limitations

- Indexed blend Type 0/3 and PC16 blending are not verified and are not rendered as supported results.
- Layer 2/3 raw-position preview is Experimental. Original dynamic scrolling, wrapping, depth changes, and initialization are not implemented.
- Palette animation, a complete game-script VM, story/save-driven runtime state, and the game's initial background state are not reproduced.
- Camera/Walkmesh game-level registration and equivalence to every original runtime configuration have not been established.
