# GaiaGIS v5.5.1 — Game Guide & Gameplay Integration

## What's New

- Reorganize game guides around Places, Treasures & Rewards, Materia, Secrets and Boss clues. Browse 58 Atlas entries and 19 reward records in five languages, with spoiler filtering and pagination. Prioritize acquisition guidance, rewards and related locations while distinguishing exact entrances, parent locations and Field-only precision.
- Add optional local Gameplay Evidence support. Measurements from tested English source resources include 451 static item grants, 170 static Materia grants, 201 Field BATTLE references, 256 Battle Scenes, 1,024 Formation records, 625 scene-enemy records, and source-verified static boss associations for Godo and Snow. These counts describe script/data records; they are not verified chest counts, unique enemy species or actual trigger counts.
- Introduce an original Buster Sword title scene and four-item menu, with a coordinated visual design across the Windows launcher and Web Viewer. Retain native folder selection, Workspace generation and browser auto-connect. The static Web Viewer can read public guide text and load a user-generated Workspace; GitHub Pages does not unpack original game folders.

## Navigation & Map-first UX

- Keep the classic deep-blue gradient and silver borders, with direct World Map, Character Explorer, Game Guides, GIS Analysis and Data & Settings entry points.
- Make character walking, the nine-character roster, vehicles and Chocobo access easier to find.
- Synchronize guide search with the map and Inspector: use a verified entrance when available; otherwise focus a trusted parent location and label its precision. Field-only entries do not invent coordinates. Switching from Native or Field to WM0 requires an explicit user action.
- Improve title-button spacing, overlays, map-target visibility and responsive interaction.

## Compatibility

- Preserve V1 Geometric Gaia and all 13 projections, WM0/WM2/WM3, Explorer, Field, Source GIS, Topology Evidence, Regional Terrain Statistics, Routing, Save Context, Atlas and Gameplay source evidence.
- No game data format, GIS mathematics or original map sources are changed. Gameplay evidence is optional and generated locally from a user's legally held, supported original PC game resources; it is not included in this public Release.

## Known Limitations

- Reliable FieldLocal treasure coordinates, independent pickup points and complete collection flags have not been verified. Full collection progress calculation is not supported.
- Gameplay parsing and measurements described above are tested for English resources. New Gameplay parsing for French, German and Spanish resources has not been verified.
- Runtime battle and story simulation are not implemented. Static source references do not prove that an encounter, grant or boss association occurs in a particular playthrough.
- A complete Workspace requires user-provided, legally held, supported original Final Fantasy VII PC resources. The public Pages Viewer cannot extract those resources.
- The updated native Windows Tk appearance has not been visually verified through a real GUI launch as part of this release process.

Users must provide data from a legally owned Final Fantasy VII installation. GaiaGIS does not distribute original game files or private Workspace/Gameplay datasets.
