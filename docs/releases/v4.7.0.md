# GaiaGIS v4.7.0 — World Map Variants & Spatial Change Analysis

## What's New

- Explore six alternate WM0 source Sections beside their six corresponding base placements. The optional World Variants research mode is off by default and requires the user to import a private, source-bound research resource.
- Select one of five cumulative reference states, from 0 through 4. Groups G2 and G4 remain atomic; the Viewer does not offer mixed half-group states.
- Inspect original face, vertex, normal, UV, attribute, compressed-source and decoded-record provenance. Conservative geometry-multiset comparisons retain duplicate occurrences and ambiguous candidate buckets rather than inventing one-to-one matches.
- Export a separate Raw Variant GeoPackage v1 containing source records, valid Polygon Z geometry, candidate relations and diagnostics. Zero-area source faces remain available in the non-spatial source table.

## Improvements

- World Variants integrates with the existing World Viewer, analysis controls and shared Inspector. Source picking keeps alternate source identities distinct from canonical WM0 face identities.
- Alternate geometry uses its own source UVs and normals while sharing the existing WM0 projection and Atlas rendering. The canonical WM0 geometry and existing V1 reconstruction are not rewritten.
- Explicit research mode keeps its selections separate from ordinary route, measurement, Explorer and other canonical WM0 capabilities. Leaving research mode restores the normal Viewer.
- Variant JSON and GeoPackage exports are private local research products. They are not included in the public source-only Viewer or the Windows portable package.

## Compatibility

- Existing Workspaces remain usable without the optional World Variants resource. Existing WM0, all thirteen projections, WM2/WM3 Native GIS, Field, Visual, Interaction, Walkmesh and GIS contracts continue to be supported.
- The portable Viewer does not bundle GDAL or QGIS. Local GeoPackage export requires a compatible GDAL installation; QGIS is optional for inspection.
- Users must provide files from a legally owned Final Fantasy VII installation. GaiaGIS does not distribute original game files, private Workspaces, Variant resources, GeoPackages or complete game-derived datasets.

## Known Limitations

- The selected source variant is a research reference state. Which variant the original game selects for a particular save or story state is **not verified**; static script evidence does not prove runtime execution.
- Face and area-contribution differences describe source records. They are not verified changed-footprint area, terrain volume, physical elevation or gameplay change.
- Native coordinates use raw source units. The GeoPackage uses Undefined Cartesian SRS (`srs_id=-1`); a QGIS client displaying “Meter” does not establish physical metres or global geographic registration.
- Original-game script execution, collision, routing, runtime switching and pixel-level rendering equivalence are not implemented or verified. The research Viewer does not alter game behaviour.
- Variant JSON and GeoPackage data are private local outputs and are not part of this public Release.
