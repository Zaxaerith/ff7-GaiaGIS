# GaiaGIS v1.2.0 — local release candidate

World Encounters / Chocobo / Gameplay GIS. Not uploaded, tagged, released or
deployed. Publication requires the user's explicit permission.

- Independent read-only enc_w.bin parser and deterministic optional local export.
- Region/terrain table lookup, documented aliases, clamp and fallback behavior.
- Encounter Zones, raw Encounter Rate, and independent WM0 Chocobo Tracks.
- Triangle gameplay Inspector: normal/special/Chocobo formation IDs and weights,
  numeric Chocobo ratings, Mystery Ninja level/region metadata and source offsets.
- Shared mesh/color buffers in five projections; mobile scrollable groups.
- Optional encounters coexist with existing V1 geometry and v1.1 Locations.

V1 mathematics, projection formulas, POI coordinates and climate research are
unchanged. No runtime/save/vehicle state, battle simulation or enemy database.
Lookup uses classic PC behavioral evidence; exact Steam 2026 runtime equivalence
remains unverified. Raw weights/rates are not absolute probabilities.

Code-only policy continues. Generate gaia-encounters.json locally from your own
FF7 installation; complete derived encounter/POI/geometry assets are not included.
GaiaGIS original code remains GPL-3.0-only; third-party licenses are retained.
