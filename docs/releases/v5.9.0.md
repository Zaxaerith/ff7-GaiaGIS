# GaiaGIS v5.9.0 — Field Gateway Network & Cross-Scene Reachability

## What's New

- Query directed, static Field reachability across scenes with up to three Gateway transfers, starting from a verified WM0 Entrance or Gateway Arrival.
- Inspect each leg's Triangle and Access path, Gateway source, exact target Arrival, and associated source evidence. Results reuse the existing Field Canvas, Graph, Inspector and return history.
- Review diagnostics for invalid geometry, disconnected Walkmesh components and the transfer limit. The query preserves source contact candidates and continues from each actual Arrival Triangle.
- Fix Explorer roaming zoom controls so `+` and `−` use the active camera's zoom behavior consistently with the mouse wheel.

## UI and Compatibility

- Preserve the five UI languages, existing navigation and map-space isolation.
- Keep Gateway results session-only and bound to the current Field Context and Walkmesh sources.

## Known Limitations

- This release analyzes static Gateway source connectivity; it does not guarantee story progression or runtime traversability.
- MAPJUMP, world exits and WM2/WM3 are not treated as automatic spatial connections.
- Reachability does not simulate the original game's scripts or runtime state.
