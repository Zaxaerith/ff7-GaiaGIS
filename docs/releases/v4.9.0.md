# GaiaGIS v4.9.0 — World Variant Comparative Spatial Analysis

## What's New

- Compare two manually selected cumulative WM0 source states at the same raw X/Z point or along one straight transect.
- Retain each source face identity, multiple heights, contacts, vertical intervals, degenerate evidence and independent SVG paths. A height delta is shown only when each side has exactly one ordinary hit.
- Distinguish missing variant-resource coverage from covered regions with no ordinary surface hit. Comparison does not silently change the displayed reference state.

## Compatibility

- Reuses the existing private World Variant JSON and Native query mathematics. No Workspace, Manifest, GIS or source-data format changes are required.
- Existing WM0, Native, Field and Workspace behavior remains available; the comparison is explicitly user initiated.

## Known Limitations

- Variant states are manual source references, not verified game or save states. Comparisons cover only the supplied variant placements.
- Coordinates and height deltas are raw Cartesian values, not verified metres or globally registered positions.
- Results do not infer a continuous ground surface, collision, navigation, changed area or volume. Original game runtime variant selection remains unverified.

Users must provide data from a legally owned Final Fantasy VII installation. GaiaGIS does not distribute original game files or private research resources.
