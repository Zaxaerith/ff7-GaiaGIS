# GaiaGIS v5.17.0 — Spatial Evidence Discovery

## What's New

- Extend the shared World and Game Guide search with spatial and script evidence discovery while preserving ordinary place search, public guides, and the existing tool directory.
- Discover places, Entrances, Fields, Items, Materia, Battle Formations, composite Enemy identities, and Encounter Sets. Reuse validated data owners and lightweight session indexes rather than creating a separate knowledge graph.
- Support typed source queries such as `field:198`, `formation:32`, `enemy:9/74`, `set:0:1`, `field:198 line:1708`, and `field:198 if:1840`. Preserve original Battle IDs, composite Scene/Enemy identities, Field-scoped instruction offsets, and original Entry aliases. Field-local script and Text ID searches require an explicit Field scope.
- Preserve distinct records when their display names match. Show original Actor, Entry, alias, instruction, and source identities in results.

## Evidence Precision and Related Records

- Distinguish verified World source geometry, independent FieldLocal geometry, static Encounter coverage, and nonspatial script relationships.
- Discover Item and Materia acquisition references through validated literal operands. Keep same-Actor and same-Entry associations as separate evidence categories.
- Preserve original LINE geometry and exact contact Triangles without assigning their coordinates to related Gameplay or Dialogue events.
- Reuse Encounter Geography, Field Evidence, and shared Source Inspector navigation. Conditional analysis remains explicitly user-triggered.

## Current Route Evidence

- Discover available Formation, Enemy, and Encounter Set associations in current valid encounter-aware route results.
- Reopen existing candidate intervals and traversed corridor pieces without recalculating routes or Encounter aggregation.
- Reuse completed World–Field exploration evidence under its existing source and session ownership. Invalidate obsolete route associations when the underlying result is cleared or replaced.

## Session Privacy and Spoiler Controls

- Keep private evidence discovery and related navigation within the current session. Private evidence targets are not written into URL fragments, Recent records, or persistent navigation targets; ordinary public place navigation retains its existing persistence behavior.
- Apply existing spoiler settings to newly introduced Gameplay search names and related evidence. Clear stale private results and actions when their Workspace or source identity changes.

## Performance and Compatibility

- Use generation-scoped lightweight global indexes and on-demand single-Field decoding, with bounded results, pagination, and cancellation.
- Support the existing five UI languages and responsive layouts. Preserve source-only public guide browsing when private assets are unavailable.
- Require no additional Workspace asset, Manifest schema change, or Workspace migration.

## Known Limitations

- Arbitrary script offsets, Actor identities, and Text IDs are not indexed across every Field. Full-text search of original dialogue bodies is not provided.
- Search does not establish runtime script execution, reward availability, or encounter probability. Same-Actor and same-Entry evidence does not establish event coordinates.
- Conditional analysis remains scene-local and bounded. Route evidence is available only for current, valid, completed analysis results. Missing or incompatible sources remain explicitly unavailable.
- This release does not add exhaustive full-game script search, global Field registration, a new routing algorithm, or a GeoPackage format.
