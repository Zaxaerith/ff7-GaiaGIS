# GaiaGIS v5.1.0 — Save Spatial Context & World State Evidence

## What's New

- Read a valid classic PC save's Field-local X/Y, original Triangle ID and raw direction. With a matching Field/Walkmesh source, show the saved position only when strict geometry and source checks place it inside or on the saved triangle. Z is interpolated from that source triangle; it is not a verified runtime character height. Outside, invalid or mismatched cases retain their raw values and rejection reason without snapping.
- For saves with a validated matching English `wm0.ev`, show a static prediction for World Variant states 0–4. Signed progress, the three condition bits and cumulative G1–G4 groups remain distinct. Opening World Variants research is explicit; the prediction does not switch the map.

## Compatibility

- Existing Workspaces and data remain usable. No Workspace or GIS regeneration is required. Global Source GIS, Native WM2/WM3, Field and existing research tools retain their formats and behavior.
- Save data is read-only and spatial context remains transient; GaiaGIS does not modify or save the original file.

## Known Limitations

- Field-position source validation matched 9 of 10 reviewed private save cases; the remaining outside-triangle case is strictly rejected. This does not establish compatibility across all game versions or languages.
- World Variant state is a static prediction from fingerprint-matched script evidence, not a verified original-game runtime world state.
- Steam 2013/2026 and multilingual game-data equivalence have not been established.

Users must provide data from a legally owned Final Fantasy VII installation. GaiaGIS does not distribute original game files, saves or private Workspace data.
