# GaiaGIS v5.7.0 — Evidence-aware Journey Planning

## What's New

- Plan an ordered journey with up to six WM0 stops and continuous routing through exact Source Nodes. The planner uses the existing CSR graph, Dijkstra solver and Routing Worker, with shared component-eligibility checks, one movement profile and one conditional-terrain policy for the journey.
- Inspect each leg's source evidence and distance in the shared Inspector. Routes reuse existing map visualization and projections, and connect to existing POI, Atlas and game-guide locations.
- Add trusted locations to a journey from the map or guide. A parent-place target remains distinct from an exact reward location; Field-only or unresolved targets are not silently converted into WM0 route endpoints.

## UI and Compatibility

- Reuse v5.6's five-domain navigation and classic FF7-inspired windows.
- Preserve Routing, Reachability, Service Area, Explorer and the existing five UI languages.
- Keep public source-only browsing available without bundling game assets. Private Workspace features require user-provided, legally obtained original game data.
- Journey results are session-only. Exported Tours preserve location visits, not solved routes.

## Known Limitations

- This is continuous ordered static WM0 routing, not a globally shortest multi-stop itinerary. Distances use the existing reference-sphere model and are not canonical FF7 travel distances.
- There are no automatic transport changes, Field traversal, Highwind flight or WM2 submarine routing.
- The planner does not infer story progression, vehicle ownership, reward collection or runtime accessibility.
- Users must provide legally obtained original game data for private Workspace features. GaiaGIS does not distribute original game assets.
