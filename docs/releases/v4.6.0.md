# GaiaGIS v4.6.0 — Native Map GIS & Source TIN Diagnostics

## What's New

- Inspect WM2/WM3 source TINs in the existing Native Viewer with exact raw X/Z corner measurements, source-face area and plane-gradient diagnostics, terrain-code contribution totals, and conservative filters for zero projected area, 3D degeneracy, duplicate faces, edge incidence and connected components.
- Inspect source-face, mesh, section, vertex and normal provenance, including original XYZ values and normal-frame details. Vertical and otherwise non-renderable projected faces remain available as source records.
- Export WM2 and WM3 to independent Native GeoPackage v1 files with `gaiagis native-gis export`. The export retains source faces and original vertex/normal table identities, padding, attributes, UVs, mesh spans, hashes and edge diagnostics. Compressed source offsets and decoded mesh offsets are recorded separately.
- Review raw measurements and source topology without modifying or repairing the original geometry. Export uses staged validation, full readback and no-overwrite delivery.

## Improvements

- Native GIS analysis is computed for the active map and is released on map/workspace changes. Source geometry identity is preserved; duplicate-coordinate vertices are not merged.
- The independent source audit and Python/Web regressions cross-check all 18,235 WM2/WM3 faces. Optional GDAL/QGIS export support remains outside the portable Viewer runtime.
- Existing Native v1, Workspace Manifest, WM0 reconstruction, Field/GIS contracts and legacy Workspace loading remain compatible.

## Compatibility

- Existing WM0, WM2 and WM3 viewing, Field research, Visual/Interaction/Walkmesh resources, GIS products and Workspace formats continue to be supported.
- Native GeoPackages are generated locally from user-provided source maps and are not included in this release. Users must provide data from a legally owned Final Fantasy VII installation; this project does not distribute original game files, private Workspaces, GeoPackages or complete game-derived datasets.
- The Windows x64 portable application does not bundle GDAL/QGIS. The optional Native GeoPackage exporter requires a compatible local GDAL installation.

## Known Limitations

- Native coordinates and measurements use raw source units. They do not represent verified physical metres, depth, altitude or slope angles. No global geographic registration, Earth CRS, vertical datum or cross-map alignment is provided; WM2Native and WM3Native are separate coordinate spaces.
- The conservative edge graph does not repair, weld, wrap, snap or infer game reachability. Duplicate geometry and unusual normal relationships are retained as evidence. Area totals are sums of source-face contributions, not unions or deduplicated surface area.
- Native TIN diagnostics do not establish runtime collision, traversal or gameplay behavior. Display normalization and relief do not change the reported raw measurements.
- Existing Field rendering limitations remain: indexed blend Type 0/3 and PC16 blending, Layer 2/3 dynamic scrolling, Palette animation, a complete script VM and original-game runtime state are not implemented or verified.
