# GaiaGIS 2.7 Windows x64 portable

Extract the entire ZIP into a writable directory of your choice, outside your FF7 installation. Keep GaiaGIS.exe beside _internal, web, config, licenses and portable-manifest.json. Run GaiaGIS.exe and select your own PC/Steam FF7 installation. A console shows generation progress; your default browser opens the local Viewer. Close with Ctrl+C in that console. Never run scripts from the FF7 directory.

Python, Node, npm, Vite and QGIS are not required by this package. Windows x64, a modern WebGL-capable browser and your own compatible FF7 installation are required. Windows may warn about this unsigned executable: no signing identity is claimed. The first run can take several minutes; subsequent runs reuse verified assets.

All GaiaGIS writes stay in the extracted directory: output/local-workspace for generated private assets; output/runtime for scratch. The game and saves are strictly read-only. Do not extract into a read-only Program Files directory or into the game. No assets are downloaded. Optional resources missing from your installation remain unavailable.

The workspace folder is generated by GaiaGIS; an original wm directory is not a workspace. My Save uses an explicit browser file chooser; .ff7 bytes and parsed values remain session-only and are not uploaded or written back. Share links exclude save/player information.

GPL-3.0-only. LICENSE.txt, THIRD_PARTY_NOTICES.txt and licenses/ contain applicable notices. GaiaGIS-source.zip contains corresponding authored source/build instructions. No FF7 assets, user saves or private workspace are included. Portable Float64 SQLite staging is a transport cache, not a GeoPackage/custom-CRS GIS export. V1 reconstruction and climate boundaries remain unchanged.
