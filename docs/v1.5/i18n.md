# Five-language viewer

Supported: `en`, `zh-CN`, `zh-TW`, `ja`, `ko`. The selector uses native language
names and is in About/help. It updates immediately without reloading geometry,
changing projections or solving routes again.

Detection priority: URL `?lang=` → saved `gaiagis.locale` →
`navigator.languages` → English. Regional language tags are normalized, including
Hant/TW/HK versus Simplified Chinese. Switching persists the preference; an
explicit language URL is updated in place while preserving the location hash.
Blocked localStorage gracefully falls back to URL/browser detection.

Small typed dictionaries use stable semantic keys, never English sentences as
translation keys. Five explicit columns have identical key and interpolation
sets. Labels, legends, static Inspector text, controls, help, loading/error
summaries, ARIA, titles and placeholders use the shared `t` function. Intl formats
display numbers. DOM bindings retain stable keys/arguments for immediate updates;
the bounded recent-render cache is a binding aid, not a translation dictionary.
Weak bindings survive cache eviction. Removed controls unsubscribe listeners.

Missing translated entries fall back to English. Completely missing keys warn
in development and safely display the key; production does not throw. New
locales require a column, native selector name, normalization and parity tests.

FF7 proper names remain verified English editorial names. Internal field names,
raw IDs, enums in provenance, opcodes, filenames, masks and hashes remain exact.
User-file freeform provenance notes are source text, not automatically translated
or interpreted. Errors show a localized summary with the original technical
diagnostic retained in the title. Projection selectors localize display names
while retaining English academic names in tooltips/info.

Local files are rendered through textContent. Dictionaries contain no HTML;
only controlled static translations appear in layout templates. Tests check
unique stable keys, five-language parity, no blank values, interpolation parity,
HTML-injection exclusion, detection, fallback, persistence, Intl and subscriber
cleanup. Browser QA covers immediate switching, ARIA, cache eviction, reload
preference, URL override and preservation of the surface geometry. Desktop,
390px and 320px layouts are tested in English/Simplified Chinese/Japanese;
Traditional Chinese/Korean are checked through automated switching/parity.
