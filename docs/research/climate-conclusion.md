# Climate: sealed Experimental / Inconclusive

The historical programme explored coarse Earth validation, atmospheric model inputs and candidate FF7 latitude/orientation mappings. It attempted to validate temperature, precipitation, snow/aridity and regional behaviour before transferring an Earth-calibrated model to Gaia.

## Earth validation gate

A plausible image or a partial global improvement was insufficient. Regional errors, seasonal/holdout behaviour, parameter sensitivity and independent physical plausibility had to pass together. Later candidates improved some quantities but did not establish a robust passing family. The gate remained failed; no validated Gaia climate conclusion followed.

## Product decision

Climate is permanently sealed **Experimental / Inconclusive**. It supplies no product coordinate authority, routing input or gameplay interpretation. V1 reconstruction mapping remains frozen; unconstrained climate hypotheses cannot justify replacing it. The UI's historical sealed notice conveys this limitation and runs no climate code.

Climate runtime modules, active configs and external model wrappers have been removed from the current tree. No climate tests or simulations are part of application regression.

Recover into an explicitly authorised isolated research scope if ever needed; do not restore sealed runtime into the product by default.
