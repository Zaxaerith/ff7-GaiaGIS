# Local Viewer QA screenshots

Generated by `node web/scripts/browser-qa.mjs` while the local Vite server is running. PNG files are ignored by Git because they show game-derived geometry and require separate public-distribution review.

Views: Globe; Globe with original triangle grid; Equirectangular; Mercator; Mollweide; Orthographic; rotated Orthographic; synthetic cap inspector; mobile touch inspector.

Headless Chrome uses a workspace-only profile and the installed browser executable, not a normal user profile. Set GAIA_BROWSER_EXECUTABLE if Chrome is installed elsewhere. Current tests also capture GPU identity and rAF timing; headless throughput is not a physical-display or phone benchmark.
